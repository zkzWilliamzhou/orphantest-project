Candidate A

Extract a Capture adapter family

Strong

Files: runner.py, adapters.py, cli.py, audit.py, contract.py, tests/test_discover.py

Before — stringly-typed dispatch

After — real seam, three adapters

Problem. Understanding what "pytest" means requires reading four modules. Observation is reconstructed in six places. The runner owns both subprocess isolation and three output grammars.

Solution. One Capture interface with three adapters; path resolution for junit_path moves into the adapter; runner.py becomes a generic executor.

Benefits. Locality: runner-specific grammar knowledge concentrates in one file per runner. Leverage: a new runner is one module instead of an if/elif edit. The interface becomes the test surface via a parametrized contract test.

Manager decision: rejected for 1.0.0. It changes capture semantics and risks the source strings that appear in findings and goldens. The user required zero function change. Deferred, not discarded.

Top recommendation — implemented

Deepen the evidence bundle module

Worth exploring → accepted

Files: cli.py → bundle.py (new), tests/test_bundle.py (new), docs/adr/0002

Before — shallow, wide interface in CLI

After — deep module, small interface

Problem. Three near-mirror helpers, a hand-rolled schema check, and a pass-through wrapper all inside the CLI. To answer "what fields does a bundle have?" a reader opened three modules.

Solution. One module owning the format behind a small interface: write_bundle, load_bundle, validate_bundle, plus the Inventory and BundleData values. The shallow wrapper was deleted, not moved.

Benefits. Locality: every invariant lives in one validator. Leverage: producer (run) and consumer (audit) share one definition. Two adapters cross the evidence-source seam (inline execution and persisted bundle), so the seam is real. The interface is the test surface: 13 new tests cross it directly.

After — tagged NodeSource

Problem. The design says three inventories; the code has four node sources. There is no type-level distinction between discovered-by-AST and observed-by-capture.

Why rejected. It changes obs.source semantics, which appear in NOT_RECONCILED findings and in golden ledgers. Poor effort-to-leverage ratio for a release whose constraint is zero function change. Recorded in ADR 0003 instead.

Do Candidate B first.
