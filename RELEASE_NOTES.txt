What it is
----------
A zero-dependency Python 3.10+ CLI that reconciles three inventories and reports
execution-inventory discrepancies under the commands a repository itself declares:

  * test files present on disk
  * test nodes statically discovered (AST, never imports target code)
  * test nodes observed as executed under the declared commands

It does NOT say the code is correct, green, or ready. Its output field is `scope`,
never `coverage`. The overall state describes the ledger only.

30-second demo (from inside orphantest/)
----------------------------------------
  python3 -m orphantest --version
  python3 -m orphantest --self-test
  python3 -m orphantest --root examples/demo_repo \
      --config examples/demo_repo/orphantest.json \
      audit --execute --trust-config

Expected: exit 1, overall DISCREPANCY_REPORTED, 5 findings, and the exact
human output documented in docs/DESIGN.md.

  python3 -m orphantest --root examples/demo_repo \
      --config examples/demo_repo/orphantest.reconciled.json \
      audit --execute --trust-config

Expected: exit 0, overall INVENTORY_RECONCILED.

Known limitations (not hidden)
------------------------------
  * Windows is not a supported platform for 1.0.0; it is absent from CI.
  * `runner: "junit"` is reserved and has no dedicated dispatch (ADR 0003).
  * Adapters cover pytest verbose, unittest verbose, and JUnit XML only.
  * Git provenance records HEAD and parents, not worktree cleanliness.
  * No star count, correctness, coverage, or test-quality claim is made.
